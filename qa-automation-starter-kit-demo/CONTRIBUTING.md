# Contributing

Thanks for taking a look at this kit!

## About contributions

This repository is the **demo / showcase** version of a commercial product. The full kit is sold on Gumroad, so contributions that re-implement features from the full kit cannot be merged.

That said, I welcome:

- **Bug reports** on the demo code shown here
- **Documentation improvements** (README clarifications, typos, broken links)
- **Suggestions** for new features or test scenarios — open an issue

## What I cannot accept

- Pull requests that re-implement `BaseTest`, `BaseApiTest`, `ConfigReader`, or other full-kit-only files
- Pull requests that add the full Azure Pipelines YAML
- Pull requests that aim to make the demo a complete framework — that's what the paid version is for

## Reporting issues

If you find an issue with the demo code, open a GitHub issue with:

- A clear description of the problem
- The Java / Maven version you're using
- Steps to reproduce

I review issues regularly and typically respond within a few days.

## Questions about the full kit

For pre-sale questions about the full version (licensing, features, refunds, etc.), the best channel is email — see the main README for contact details.

Or open a GitHub issue labelled `question` and I'll get back to you.
