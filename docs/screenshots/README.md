# Screenshots

Add these images here before pushing to GitHub so they render in the main README:

1. **`allure-report.png`** — A screenshot of the Allure HTML report showing
   Epics, Features, Stories, and Severity. Generate locally after running the
   full kit and capture the dashboard view.

2. **`azure-pipeline.png`** — A screenshot of the Azure Pipelines run showing
   all three stages (API Tests, UI Tests, Quality Gate) passing in green.

3. **`project-structure.png`** — A screenshot of the project tree opened in
   IntelliJ IDEA (or VS Code) showing the full folder structure.

These images significantly improve conversion — visitors trust what they can see.

The images are not included in the demo repo on purpose. Capture them from your
own full-kit run after you've published the kit on Gumroad.
